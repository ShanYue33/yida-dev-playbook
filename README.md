# Yida Dev Notes

A practical knowledge base for DingTalk Yida development, covering low-code configuration, custom development, workflow design, integrations, troubleshooting, and lessons learned from real-world implementation challenges.

中文：沉淀宜搭开发、配置与排障中的实践经验，帮助开发者更高效地定位问题、设计方案和交付应用。

## What You'll Find Here

- Form design, field configuration, and data rules
- Workflow design, approval rules, and permission management
- Custom pages, JavaScript/JSX development, and runtime debugging
- API integrations, connectors, and data synchronization
- Common issues, root-cause analysis, and verified solutions
- Delivery checklists and implementation best practices

## Repository Structure

- `01-form-and-fields` — 表单、字段、公式与业务规则
- `02-workflows` — 流程设计、审批规则与退回处理
- `03-custom-development` — 自定义页面、JSX、DOM/CSS 与前端调试
- `04-integrations` — OpenAPI、连接器与系统集成
- `05-troubleshooting` — 常见问题、排查路径与解决方案
- `06-checklists` — 开发、测试、发布与验收清单

## Principles

- Prefer verified solutions over assumptions.
- Record the context, symptoms, root cause, solution, and validation result.
- Separate platform limitations from custom-code issues.
- Validate permissions, schemas, workflow states, and runtime behavior before release.
- Keep all examples anonymized and free of credentials or sensitive business data.

## Note Template

Each note should preferably include:

1. Scenario and expected behavior
2. Symptoms or error messages
3. Root-cause analysis
4. Solution and implementation details
5. Validation steps
6. Applicable scope and limitations
